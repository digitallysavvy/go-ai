# Google configuration

Package `github.com/digitallysavvy/go-ai/pkg/providers/google`. Create a provider with `google.New(google.Config{...})`. When `APIKey` is empty, the provider reads `GOOGLE_GENERATIVE_AI_API_KEY`.

The tables on this page are generated from the Go source. For usage, see the [Google provider page](../../05-providers/04-google.mdx).
