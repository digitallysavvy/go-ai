# API Reference

Complete reference documentation for all Go-AI SDK APIs, types, and interfaces.

## Core AI Functions

High-level functions for working with AI models:

- [GenerateText](./ai/generate-text.mdx) - Generate text completions
- [StreamText](./ai/stream-text.mdx) - Stream text completions in real-time
- [GenerateObject](./ai/generate-object.mdx) - Generate structured data
- [StreamObject](./ai/stream-object.mdx) - Stream structured data
- [Embed](./ai/embed.mdx) - Generate embeddings for text
- [EmbedMany](./ai/embed-many.mdx) - Generate embeddings for multiple texts
- [Rerank](./ai/rerank.mdx) - Rerank documents by relevance
- [GenerateImage](./ai/generate-image.mdx) - Generate images from text
- [Transcribe](./ai/transcribe.mdx) - Transcribe audio to text
- [GenerateSpeech](./ai/generate-speech.mdx) - Generate speech from text
- [Agent](./ai/agent.mdx) - The `agent.Agent` interface (in `pkg/agent`)
- [ToolLoopAgent](./ai/tool-loop-agent.mdx) - `agent.ToolLoopAgent`, the SDK's tool-using agent (in `pkg/agent`)

Functions for working with tools and utilities:

- [IsStepCount](./ai/step-count-is.mdx) - Stop condition: stop after n steps
- [HasToolCall](./ai/has-tool-call.mdx) - Stop condition: stop when a tool is called
- [StopCondition](./ai/stop-condition.mdx) - The StopCondition type and StopWhen evaluation
- [GenerateID](./ai/generate-id.mdx) - Generate unique IDs
- [Callback Events](./ai/callback-events.mdx) - Structured lifecycle events for observability
- [Stream Transport Helpers](./ai/stream-transport-helpers.mdx) - Convert stream results to HTTP-friendly payloads
