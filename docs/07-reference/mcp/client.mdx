# MCP client

Package `github.com/digitallysavvy/go-ai/pkg/mcp` is a Model Context Protocol client. It connects to an MCP server, lists its tools, resources and prompts, and converts server tools into `types.Tool` values for `GenerateText`, `StreamText` and agents.

OAuth helpers are in [MCP OAuth](./oauth.mdx). Message and capability types are in [MCP protocol types](./protocol-types.mdx).

## Creating a client

| Function | Description |
| --- | --- |
| `mcp.CreateStdioMCPClient(command string, args []string) (*MCPClient, error)` | Starts a local server as a child process and talks to it over stdin and stdout. |
| `mcp.CreateHTTPMCPClient(url string, oauth *OAuthConfig) (*MCPClient, error)` | Connects to a remote server over streamable HTTP. |
| `mcp.CreateSSEMCPClient(url string, oauth *OAuthConfig) (*MCPClient, error)` | Connects over the legacy SSE transport. |
| `mcp.CreateMCPClient(config MCPClientConfig, transport Transport) (*MCPClient, error)` | Creates a client over any transport with explicit configuration. |
| `mcp.NewMCPClient(transport Transport, config MCPClientConfig) *MCPClient` | Creates a client without connecting. Call `Connect` yourself. |

| `ListResourceTemplates(ctx) (*ListResourceTemplatesResult, error)` | Lists resource templates. |
| `ReadResource(ctx, uri string) (*ReadResourceResult, error)` | Reads a resource. |
| `ListPrompts(ctx) ([]MCPPrompt, error)` | Lists the first page of prompts. |
| `ListPromptsWithCursor(ctx, cursor string) (*ListPromptsResult, error)` | Lists one page of prompts from a cursor. |
| `GetPrompt(ctx, name string, arguments map[string]interface{}) (*GetPromptResult, error)` | Gets a prompt with arguments filled in. |
| `Complete(ctx, params CompleteRequestParams) (*CompleteResult, error)` | Requests argument completions for a prompt or resource template. |
| `OnElicitationRequest(handler func(context.Context, ElicitationRequest) (ElicitResult, error))` | Registers the handler for server-initiated elicitation requests. |
| `ServerCapabilities() ServerCapabilities` | Capabilities the server reported. |
| `ServerInfo() ServerInfo` | Server name and version. |
| `ServerInstructions() string` | Instructions the server sent. |
| `InitializeResult() InitializeResult` | The raw initialize result. |

Requests for tools, resources or prompts fail with `Server does not support tools` (or `resources`, `prompts`) when the server did not advertise that capability during the handshake. A request on a closed client, or after the transport dropped, fails with `Attempted to send a request from a closed client`. A request that was in flight when the connection dropped fails with `Connection closed`. If the handshake fails, `Connect` closes the transport before returning.

Set `MCPClientConfig.InitialInitializeResult` to reuse the initialize result of an earlier session: `Connect` starts the transport and applies it without sending `initialize`.

`MaxRetries` retries only `tools/call` requests that fail with a transient error: HTTP 408, 409, 429 or 5xx, or a connection-level failure. JSON-RPC application errors and results with `IsError` set are never retried.

## Transports

All transports implement `mcp.Transport`:

```go
type Transport interface {
	Connect(ctx context.Context) error
	Close() error
	Send(ctx context.Context, message *MCPMessage) error
	Receive(ctx context.Context) (*MCPMessage, error) // io.EOF when closed
	IsConnected() bool
}
```

| Constructor | Transport |
| --- | --- |
| `mcp.NewStdioTransport(StdioTransportConfig) *StdioTransport` | Child process over stdin and stdout. |
| `mcp.NewHTTPTransport(HTTPTransportConfig) *HTTPTransport` | Streamable HTTP, with session resumption and an inbound SSE stream. |
| `mcp.NewSSETransport(SSETransportConfig) *SSETransport` | Legacy SSE. |

### OAuth with an AuthProvider

Set `AuthProvider` (an [`mcp.OAuthClientProvider`](./oauth.mdx)) on `HTTPTransportConfig` or `SSETransportConfig` to let the transport run the OAuth flow itself. Every request carries the provider's access token as a bearer token. On a 401 response the transport calls [`mcp.Auth`](./oauth.mdx) once, shared by all concurrent requests, and retries the request. If `Auth` returns `REDIRECT`, the provider's `RedirectToAuthorization` has been called and the request fails with `*mcp.UnauthorizedError`; finish the flow by calling `Auth` with the authorization code. `AuthHTTPClient` sets the HTTP client used for the discovery, registration and token requests.

Event-stream bodies are not subject to `TimeoutMS`: the timeout bounds a POST until its response headers arrive (and the whole exchange for non-streamed responses), but a standing SSE stream or a streamed POST response stays open. The stdio transport keeps its child process alive after the context given to `Connect` is cancelled, inherits the parent's stderr (or writes it to `StdioTransportConfig.Stderr`, for example `io.Discard`), and skips stdout lines that are not JSON-RPC (reporting them through `StdioTransportConfig.OnError`).

## Events (experimental)

Events let a client discover and subscribe to server events delivered by webhook. The API is experimental and may change in any release. Configure it with `MCPClientConfig.ExperimentalEvents`; the server must advertise the `events` capability, otherwise calls return `Server does not support events`.

Set exactly one of `Store` or `Adapter`. Setting both makes `Connect` return an error before the transport starts.

| Type | Description |
| --- | --- |
| `mcp.MCPEventsConfig` | `Store` (direct webhook subscriptions), `Adapter` (managed subscriptions) and `ValidateArguments` (optional, `Store` only). |
| `(*MCPClient).ExperimentalEvents() *mcp.MCPEvents` | Direct API: `List`, `Subscribe`, `Refresh`, `Unsubscribe`. `List` works without a store; the others need `Store`. |
| `(*MCPClient).ExperimentalManagedEvents() mcp.ManagedMCPEvents` | Managed API when an `Adapter` is set (nil otherwise): `List` over MCP, plus `Subscribe`, `GetSubscription`, `ListSubscriptions`, `Unsubscribe` delegated to the adapter. |
| `mcp.MCPEventStore` | Durable, private storage for subscriptions, scoped to one server and principal. `Update` must atomically merge only the fields set in the `MCPEventSubscriptionPatch`. Records hold the signing secret, so never expose them to a browser. |
| `mcp.MCPEventAdapter` | `CreateAdapter(MCPEventAdapterContext) (MCPEventOperations, error)` is called once from `NewMCPClient`, before the transport starts. The context holds the transport type (`http`, `sse`, `custom`) and its configured URL (empty for `custom`). Errors are returned by `Connect`. |
| `mcp.ExperimentalCreateMCPEventWebhook(opts)` | Returns an `http.Handler` for webhook deliveries. Mount it at the callback URL before subscribing. |

`Subscribe` requires an HTTPS callback URL without credentials or fragments (`AllowInsecureLocalhost` permits `http://127.0.0.1` and `http://[::1]` for development), follows catalog pagination, persists a `pending` record with the generated `whsec_` secret and a `mcp_event_subscription` routing parameter, and only then sends `events/subscribe`. `Refresh` and `Unsubscribe` accept an `MCPEventSubscriptionRef` with a server `ID` or the local `Key`. Optional TTLs use `mcp.Nullable`: leave it unset to omit `ttlMs`, or pass `mcp.NullableNull[int64]()` to request a non-expiring subscription.

The webhook handler verifies the Standard Webhooks v1 signature over the exact body (5 minute tolerance, 256 KiB limit), echoes signed verification challenges, and responds 503 until the subscription is `active` so the server retries. `OnEvent`, `OnGap` and `OnTerminated` run before cursor, truncation or deletion state is saved; an error from a callback or the store becomes a 503. Deliveries can be duplicated or reordered, so deduplicate by subscription ID and event ID (or message ID).

```go
package main

import (
	"context"
	"log"
	"net/http"

	"github.com/digitallysavvy/go-ai/pkg/mcp"
)

func run(store mcp.MCPEventStore, transport mcp.Transport) error {
	ctx := context.Background()

	webhook, err := mcp.ExperimentalCreateMCPEventWebhook(mcp.MCPEventWebhookOptions{
		Store: store,
		OnEvent: func(ctx context.Context, args mcp.MCPEventWebhookEventArgs) error {
			log.Printf("event %s for %s", args.Event.EventID, args.Subscription.Name)
			return nil
		},
	})
	if err != nil {
		return err
	}
	go func() { _ = http.ListenAndServe(":8080", webhook) }()

	client := mcp.NewMCPClient(transport, mcp.MCPClientConfig{
		ExperimentalEvents: &mcp.MCPEventsConfig{Store: store},
	})
	if err := client.Connect(ctx); err != nil {
		return err
	}
	defer client.Close()

	_, err = client.ExperimentalEvents().Subscribe(ctx, mcp.SubscribeEventOptions{
		Name:      "comment.created",
		Arguments: map[string]interface{}{"document_id": "doc_1"},
		Delivery:  mcp.MCPEventWebhookDelivery{URL: "https://app.example/events"},
	})
	return err
}

func main() {}
```

## Request options

`mcp.WithRequestOptions(ctx, mcp.RequestOptions{TimeoutMS, MaxTotalTimeoutMS})` puts per-request limits on a context. The client call made with it uses the smaller of the two as its timeout instead of `RequestTimeoutMS` (TS `RequestOptions`). Cancelling the context is the TS `signal`: the call fails with `Request was aborted`, and `errors.Is(err, context.Canceled)` still matches.

`MCPClientConfig.InitializationOptions` bounds `Connect` the same way. It fails with `MCP client initialization timed out after <n>ms`, or `MCP client initialization was aborted` when the `Connect` context is cancelled.

A response with no `id`, or with an `id` no request is waiting for, is reported to `MCPClientConfig.OnError` as `Protocol error: Received a response without a message ID: ...` (or `... for an unknown message ID: ...`).
