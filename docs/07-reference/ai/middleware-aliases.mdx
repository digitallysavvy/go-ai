# Middleware Aliases

The `pkg/ai` package re-exports middleware APIs for parity-oriented discoverability.

## Type aliases

- `ai.LanguageModelMiddleware`
- `ai.EmbeddingModelMiddleware`
- `ai.ExtractReasoningOptions`
- `ai.ExtractJSONOptions`
- `ai.AddToolInputExamplesOptions`
