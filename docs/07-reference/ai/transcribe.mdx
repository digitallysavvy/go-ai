# Transcribe

Converts audio bytes to text using a transcription model.

## Signature

```go
func Transcribe(ctx context.Context, opts TranscribeOptions) (*TranscribeResult, error)
```

## TranscribeOptions

| Field | Type | Required | Description |
|---|---|---|---|
| `Model` | `provider.TranscriptionModel` | Yes | Transcription model |
| `Audio` | `[]byte` | Yes | Audio bytes |
| `MimeType` | `string` | No | Audio MIME type |
| `Language` | `string` | No | Requested language code |
| `Timestamps` | `bool` | No | Whether to request timestamps |
| `Headers` | `map[string]string` | No | Extra request headers |

## TranscribeResult

| Field | Type | Description |
|---|---|---|
| `Text` | `string` | Transcribed text |
| `Segments` | `[]TranscriptionSegment` | Segment-level timing entries |
| `Language` | `string` | Language value carried on the request/result |
| `DurationInSeconds` | `*float64` | Optional duration (provider-dependent) |
| `Timestamps` | `[]types.TranscriptionTimestamp` | Provider timestamp entries |
| `Warnings` | `[]types.Warning` | Provider warnings (if exposed) |
| `Responses` | `[]*types.ResponseMetadata` | Response metadata entries |
| `ProviderMetadata` | `map[string]interface{}` | Provider-specific metadata |
| `Usage` | `types.TranscriptionUsage` | Usage metrics |

## Example

```go
audioData, _ := os.ReadFile("audio.mp3")

result, err := ai.Transcribe(ctx, ai.TranscribeOptions{
    Model:    transcriptionModel,
    Audio:    audioData,
    MimeType: "audio/mpeg",
})
if err != nil {
    // handle
}

fmt.Println(result.Text)
```
