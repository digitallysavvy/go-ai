# GenerateSpeech

Generates speech audio from text.

## Signature

```go
func GenerateSpeech(ctx context.Context, opts GenerateSpeechOptions) (*GenerateSpeechResult, error)
```

## GenerateSpeechOptions

| Field | Type | Required | Description |
|---|---|---|---|
| `Model` | `provider.SpeechModel` | Yes | Speech model |
| `Text` | `string` | Yes | Input text |
| `Voice` | `string` | No | Voice identifier |
| `Speed` | `*float64` | No | Speech speed |
| `Headers` | `map[string]string` | No | Extra request headers |

## GenerateSpeechResult

| Field | Type | Description |
|---|---|---|
| `Audio` | `types.GeneratedFile` | Generated audio file payload |
| `Warnings` | `[]types.Warning` | Provider warnings (if exposed) |
| `Responses` | `[]*types.ResponseMetadata` | Response metadata entries |
| `ProviderMetadata` | `map[string]interface{}` | Provider-specific metadata |
| `Usage` | `types.SpeechUsage` | Speech usage metrics |

## Example

```go
result, err := ai.GenerateSpeech(ctx, ai.GenerateSpeechOptions{
    Model: speechModel,
    Text:  "Hello from Go AI SDK",
    Voice: "alloy",
})
if err != nil {
    // handle
}

_ = os.WriteFile("output.mp3", result.Audio.Data, 0644)
```
