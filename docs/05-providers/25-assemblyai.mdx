# AssemblyAI Provider

AssemblyAI provides speech-to-text transcription models. The current Go provider
implements the shared `provider.TranscriptionModel` interface and is used
through `ai.Transcribe`.

## Setup

```go
import (
    "context"
    "fmt"
    "log"
    "os"

    "github.com/digitallysavvy/go-ai/pkg/ai"
    "github.com/digitallysavvy/go-ai/pkg/providers/assemblyai"
)
```

```go
provider := assemblyai.New(assemblyai.Config{
    APIKey: os.Getenv("ASSEMBLYAI_API_KEY"),
})

model, err := provider.TranscriptionModel(assemblyai.ModelAssemblyAISTT37)
if err != nil {
    log.Fatal(err)
}
```

## Transcribe Audio

Pass local audio bytes to `ai.Transcribe`; the AssemblyAI provider uploads the
audio and polls until the transcript is complete.

```go
audioData, err := os.ReadFile("recording.mp3")
if err != nil {
    log.Fatal(err)
}

result, err := ai.Transcribe(context.Background(), ai.TranscribeOptions{
    Model:    model,
    Audio:    audioData,
    MimeType: "audio/mpeg",
    ProviderOptions: map[string]interface{}{
        "assemblyai": map[string]interface{}{
            "languageCode": "en",
        },
    },
})
if err != nil {
    log.Fatal(err)
}

fmt.Println(result.Text)
```

You can also provide a URL and let the SDK download it before invoking the
provider:

```go
result, err := ai.Transcribe(context.Background(), ai.TranscribeOptions{
    Model:    model,
    AudioURL: "https://example.com/recording.mp3",
    ProviderOptions: map[string]interface{}{
        "assemblyai": map[string]interface{}{
            "languageCode": "en",
        },
    },
})
```

## Timestamps

AssemblyAI word timings are returned as normalized segments when available.

```go
result, err := ai.Transcribe(context.Background(), ai.TranscribeOptions{
    Model:    model,
    Audio:    audioData,
    MimeType: "audio/mpeg",
    ProviderOptions: map[string]interface{}{
        "assemblyai": map[string]interface{}{
            "speakerLabels": true,
        },
    },
})
if err != nil {
    log.Fatal(err)
}

for _, segment := range result.Segments {
    fmt.Printf("[%.2f-%.2f] %s\n", segment.StartSecond, segment.EndSecond, segment.Text)
}
```

## Models

| Constant | Model ID | Notes |
|---|---|---|
| `assemblyai.ModelAssemblyAISTT37` | `assemblyai-stt-3-7` | Flagship transcription model (also selected by `TranscriptionModel("")`) |
| `assemblyai.ModelUniversal35Pro` | `universal-3-5-pro` | Deprecated by AssemblyAI; returns a deprecation warning pointing to `assemblyai-stt-3-7` |
| `assemblyai.ModelUniversal2` | `universal-2` | Supported; returns a warning suggesting `assemblyai-stt-3-7` |
| `assemblyai.SpeechModelTTS1` | `assemblyai-tts-1` | Text-to-speech (`SpeechModel`) |

Every model ID, including any other string, is sent through `speech_models`.
`assemblyai.ModelBest` (`best`) and `assemblyai.ModelUniversal3Pro`
(`universal-3-pro`) are deprecated constants kept for v0.5 code: they are sent
as given, with no special handling, and AssemblyAI rejects the IDs it no
longer accepts.

`TranscriptionOptions.AudioBase64` is decoded before the upload; a malformed
base64 string fails before any request.

## Text-to-Speech

`SpeechModel` returns the `assemblyai-tts-1` model (`POST /v1/speech` on
`https://tts.us.assemblyai.com`; `Config.SpeechBaseURL` overrides the host).
The output format maps to an encoding (`mp3` by default, `wav`, `pcm`, `mulaw`,
`alaw`); `ProviderOptions["assemblyai"]` (`assemblyai.SpeechModelOptions`)
sets `encoding`, `container`, `sampleRate` and `bitRate` and overrides it.
Unsupported settings (speed other than 1, instructions, an unsupported
language) produce warnings.

```go
speechModel, err := provider.SpeechModel(assemblyai.SpeechModelTTS1)
if err != nil {
    log.Fatal(err)
}

speech, err := ai.GenerateSpeech(context.Background(), ai.GenerateSpeechOptions{
    Model: speechModel,
    Text:  "Hello from the Go AI SDK.",
    Voice: "aai-kyla",
})
if err != nil {
    log.Fatal(err)
}
_ = speech
```
