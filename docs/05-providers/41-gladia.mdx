# Gladia Provider

Gladia provides speech-to-text transcription. The current Go provider
implements the shared `provider.TranscriptionModel` interface and is used
through `ai.Transcribe`.

## Setup

```go
import (
    "context"
    "fmt"
    "log"
    "os"

    "github.com/digitallysavvy/go-ai/pkg/ai"
    "github.com/digitallysavvy/go-ai/pkg/providers/gladia"
)
```

```go
provider := gladia.New(gladia.Config{
    APIKey: os.Getenv("GLADIA_API_KEY"),
})

model, err := provider.TranscriptionModel("")
if err != nil {
    log.Fatal(err)
}
```

Pass an empty string (or `"default"`) to let Gladia pick its default model,
or `gladia.ModelSolaria1` / `gladia.ModelSolaria3` (`solaria-*` IDs) to send
that model as `model`. Any other model ID is not sent, and the call returns an
`unsupported` warning for `modelId` (see
[Known differences](../08-migration-guides/known-differences.mdx#gladia-model-ids)).

Jobs are polled every second for up to 10 minutes. Set `Config.PollInterval` /
`Config.PollTimeout`, or the per-call provider options `pollIntervalMs` /
`pollTimeoutMs` (whole milliseconds), to change that. Invalid settings fail
the call before the upload.

## Transcribe Audio

```go
audioData, err := os.ReadFile("meeting.mp3")
if err != nil {
    log.Fatal(err)
}

result, err := ai.Transcribe(context.Background(), ai.TranscribeOptions{
    Model:    model,
    Audio:    audioData,
    MimeType: "audio/mpeg",
    ProviderOptions: map[string]interface{}{
        "gladia": map[string]interface{}{
            "languageConfig": map[string]interface{}{"languages": []string{"en"}},
        },
    },
})
if err != nil {
    log.Fatal(err)
}

fmt.Println(result.Text)
if result.DurationInSeconds != nil {
    fmt.Printf("Duration: %.2f seconds\n", *result.DurationInSeconds)
}
```

## Timestamps

```go
result, err := ai.Transcribe(context.Background(), ai.TranscribeOptions{
    Model:    model,
    Audio:    audioData,
    MimeType: "audio/mpeg",
})
if err != nil {
    log.Fatal(err)
}

for _, segment := range result.Segments {
    fmt.Printf("[%.2f-%.2f] %s\n", segment.StartSecond, segment.EndSecond, segment.Text)
}
```

## Options (Gladia v2 API)

Options go under `ProviderOptions["gladia"]` (`gladia.TranscriptionModelOptions`
keys). Language and vocabulary use the v2 shapes: `languageConfig`
(`languages`, `codeSwitching`) and `customVocabularyConfig`. The v1 keys
`language`, `detectLanguage`, `enableCodeSwitching`, `codeSwitchingConfig` and
a `customVocabulary` array are still read and translated, with a `deprecated`
warning. The v1 fields the v2 API dropped (`contextPrompt`, `moderation`,
`chapterization`, `nameConsistency`, `structuredDataExtraction`,
`structuredDataExtractionConfig`, `displayMode`, `diarizationConfig.enhanced`)
are not sent and return an `unsupported` warning. Requests carry the
`x-gladia-version` header (a caller header of that name wins).

`result.ProviderMetadata["gladia"]` holds the job `status`, `error_code` and
the whole Gladia `result` object (every add-on such as summarization,
translation or sentiment analysis, and the utterances).
