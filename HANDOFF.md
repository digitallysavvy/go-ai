## Gotchas / decisions
- **Single `ToolUIPart` struct** for static (`tool-<name>`) and dynamic (`dynamic-tool` + ToolName) parts; aliases for TS names. Parts decoded from JSON are pointers; guards accept value or pointer (`AsToolUIPart`).
- **nil = absent**: `Input` nil is omitted for input-streaming/output-error, serialized as `null` for other states; `Output` always emitted for output-available. Explicit `null` vs absent is not distinguished (edge cases only). Tri-state bools (`ProviderExecuted`, `Preliminary`, `IsAutomatic`, `Approved`) are `*bool` for round-trip fidelity.
- **ConvertToModelMessages** emits `types.ToolCallContent` in Content (TS parity) AND mirrors non-provider-executed calls into `Message.ToolCalls`, because OpenAI chat / Google converters read only `ToolCalls`; Anthropic and OpenAI Responses de-duplicate by ID. Non-map tool input is stored in `ToolCallContent.Input` as raw string (string input) or JSON.
- File URLs validated like `new URL()` (scheme required) → `MessageConversionError`.
- Validation is done on decoded JSON (`uiMessagesToJSONValue` accepts []UIMessage, []UIMessageChunk, raw JSON, etc.), then decoded to typed structs (numbers become float64). Structural errors are `*providererrors.ValidationError` (TypeValidationError alias); missing messages → `*providererrors.InvalidArgumentError`. Messages are zod-like but not byte-identical zod error text.
- `Tools == nil` means "no tools provided" (TS `tools == null`); empty non-nil slice validates against empty set.
- Go schemas cannot transform values; "parsed" value = `schema.ApplyDefaults`; transforms must be modeled with `ExperimentalRefineToolInput`.
- `ReadUIMessages` reuses the existing map reducer (`uiMessageCallbackState`) and converts each snapshot; processing errors end the stream (TS transform error), `error` chunks only report unless TerminateOnError.
- Files changed outside new files: `pkg/provider/types/message.go` (Reason field), `pkg/ai/content_parts.go`, `pkg/ai/generate.go` (1 line), `pkg/providerutils/response_message.go`, `pkg/ai/ui_message_stream.go` (reducer + reason chunk).
