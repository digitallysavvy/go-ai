# Recipes

Short, complete programs for common tasks. Each folder is one recipe and has a matching page in the docs under [Recipes](https://goaisdk.com/docs/recipes). They compile without API keys; set the keys named in each file to run them.

| Folder | Task |
| --- | --- |
| `usechat-backend` | Serve a `useChat` frontend from Go |
| `tool-approval` | Pause a tool call until a user approves it |
| `mcp-tools` | Use tools from an MCP server |
| `structured-output` | Get typed data from a model |
| `switch-providers` | Change providers without changing code |
| `claude-reasoning` | Use Claude with reasoning |
| `harness-coding-agent` | Run Claude Code or Codex in a sandbox |
| `rag-embeddings` | Retrieve context with embeddings |
| `rate-limits-retries` | Retries, timeouts and rate-limit errors |
| `mock-model-tests` | Test code that calls a model |
| `agent-with-tools` | Run a tool loop with an agent |
| `stream-text` | Stream text as it arrives |
